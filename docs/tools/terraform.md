# Terraform

The dedicated NubeStack Cloud Terraform provider and its configuration guide are coming later. No NubeStack provider name, registry entry or resource syntax is published here.

The cloud's existing native OpenStack access can be used by compatible OpenStack tools with the appropriate project-location credentials. Start with [native access](/native-access/overview.md) and [service-account credentials](/organization/service-accounts.md#native-credentials). This documentation does not yet provide a validated Terraform configuration.
