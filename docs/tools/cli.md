# NubeStack CLI

!!! info "Coming later"

    A NubeStack Cloud command-line tool, for the same tasks as the console and the API, is planned
    but not released. Nothing here is available yet.

## Use meanwhile

- **The API with `curl`** for anything the console does in a project. Every service page has the
  request in its **API** tab; [API](../api/index.md) shows how to set up a key.
- **The OpenStack CLI** to work directly with a location's resources, signed in as you:
  [OpenStack CLI](../native-access/openstack-cli.md).
