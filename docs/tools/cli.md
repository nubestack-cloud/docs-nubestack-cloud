# NubeStack CLI

The dedicated NubeStack Cloud CLI is coming later. There are no NubeStack installation commands or CLI subcommands to document yet.

For scripts today, use the [customer API](../api/index.md). To work directly with a location's resources, use the [OpenStack CLI with browser sign-in](../native-access/openstack-cli.md).
