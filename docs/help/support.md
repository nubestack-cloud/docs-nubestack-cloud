# Support

Use the support contact NubeStack supplied with your invitation or account onboarding. A public support address, ticket portal, response-time policy and service-status URL have not been specified for this documentation yet.

## Include these details

- What you expected and what happened, including the exact refusal or problem code.
- Organization and project IDs, the location and affected resource IDs.
- Operation ID and request ID, if available.
- Time of the problem with its time zone.
- A short sequence of steps or a redacted request that reproduces it.
- Whether it happens in the NubeStack console, customer API or native tools.

Do not include API keys, private SSH or certificate keys, invitation fragments, native credential secrets or one-time console URLs. Console logs can also contain secrets; redact them before sharing.

For an access incident, state which account or credential is affected and whether you have revoked it. For a failed change, leave the operation ID available even if you have cleaned up the resource.

Try [Troubleshooting](/help/troubleshooting.md) for common dependency, quota, networking and sign-in refusals.
