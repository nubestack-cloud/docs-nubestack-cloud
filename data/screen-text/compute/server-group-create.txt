Instances a host may run
1 keeps every instance on its own host. More lets a host take that many, still never more.

A host is one machine. Hosts are not availability zones: two hosts can share a rack, power and zone. The location's admission check does not plan a group's spread, so a strict group can refuse an instance while the location still has room for others.
