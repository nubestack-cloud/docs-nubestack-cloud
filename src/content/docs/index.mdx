## What NubeStack Cloud is

NubeStack Cloud is a public cloud run by NubeStack. You sign in once, work in **projects**, and
choose the **locations** each project runs in. Each location is a separate OpenStack cloud with its
own capacity, networks and storage: what you make in Karachi stays in Karachi, and trouble in one
location never stops the other.

You use it three ways, all with the same account and the same permissions:

- **The console**, in your browser, for everything on these pages.
- **The API**, for your scripts and pipelines, with a service account's API key.
- **Each location's own OpenStack tools**: its Horizon dashboard and the OpenStack CLI, signed in
  with your NubeStack Cloud account.
